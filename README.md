# lit-auto-eval

洛阳理工学院教务系统（lljw.lit.edu.cn）**随堂评价自动提交**油猴脚本。

## 作用

打开随堂评价列表页后，脚本注入一个悬浮面板，点「开始」即自动完成：

1. 从第 1 页开始逐页扫描所有待评价课程（只处理 `pj('...')` 链接的行，已评价的自动跳过）；
2. 每条随机生成总分：在 `评分区间` 与页面允许区间（`data-zdf`/`data-zgf`）的交集内取随机整数，逐档调整单选选项使页面实测总分 `#wjpf` 落入该区间，**落不进就不提交**；
3. 评语从评语池里随机取一条填入（页面没有评语框则跳过）；
4. 调用页面原生 `savePj()` 提交，自动处理三类弹窗：
   - 「评价成功」提示框（原生 `<dialog>`，每秒清扫）；
   - 提交后的确认弹窗；
   - 「指标调查」询问框（自动点跳过/取消，问卷已打开则直接关掉）；
5. 等列表行变为「已评价」做实证，才算成功；
6. 自动翻页，直到没有待评价项或达到条数上限。

## 环境要求

- 浏览器 + 任意用户脚本管理器（Tampermonkey / Violentmonkey）；
- 已登录教务系统，`@match https://lljw.lit.edu.cn/*`，`@run-at document-idle`，`@grant none`，不依赖任何外部库。

## 安装

### 方式一：ScriptCat（推荐）

1. 打开脚本市场主页：<https://scriptcat.org/zh-CN/script-show-page/9137>
2. 登录 ScriptCat 后点「安装脚本」，浏览器会唤起 ScriptCat 扩展确认安装；
3. 确认后脚本即装好，无需手动粘贴代码，后续更新也由 ScriptCat 自动拉取。

### 方式二：Tampermonkey 手动安装

Tampermonkey → 「添加新脚本」→ 清空编辑器 → 粘贴 `lit-auto-eval.js` 全文 → 保存。
（或把 `lit-auto-eval.js` 拖进浏览器，Tampermonkey 会自动接管。）

## 使用

1. 登录教务系统，进入随堂评价列表页（路径含 `/new/student/ktpj`）；
2. 页面右上角出现「随堂评价自动提交」深色悬浮面板；
3. 在面板「设置」区改参数 → **保存设置** → 点 **开始**；
4. 日志区实时滚动每条的评分/评语/结果；随时可点 **中止**（中止后当前条不会再提交）。

### 面板设置（存 `localStorage['lit-pj-cfg']`，跨次保留）

| 项 | 默认 | 说明 |
|---|---|---|
| 评分区间 | 80–100 | 与页面 `data-zdf`/`data-zgf` 取交集；交集为空直接报错不提交 |
| 评语池 | `无` | 一行一条，每条提交随机取一条 |
| 重试次数 | 2 | 单条最多尝试次数（含首次），1–10 |
| 条数上限 | 200 | 单次运行最多处理条数（保护上限），1–1000 |

## 安全机制（宁停勿错）

**提交不可逆。** 以下任一情况脚本立即停止并报告，不会盲目重试：

- 单条用尽重试次数仍失败 → 停，报剩余数；
- 表单里存在必答的**非单选**题（`data-sfbt=1` 且 `txdm≠1`）→ 拒绝作答该条；
- 提交后行未变为「已评价」→ 计为失败（可能已提交，重试可能重复）；
- 「指标调查」确认框连续 6 次关不掉 → 停，需手动关闭；
- 达到条数上限 → 停。

成功/失败均计入面板统计，失败明细在日志区。

## 已知边界

- 只作答单选题（`data-txdm=1`）；填空/评语由评语池处理；
- 评价截止 **2026-11-20 12:00**，过期系统入口关闭，脚本无能为力；
- 站方改版（选择器 `pj(...)`、`#pj-form`、`savePj` 变动）会导致脚本失效，需同步修改。
